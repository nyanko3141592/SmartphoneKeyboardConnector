# iPhone のカメラをオプティカルフローでマウスにする

<<画像：iPhone とノート PC、奥に AR グラス。リアカメラを少し傾けてカーソルを動かしている>>

## きっかけ

iPhone をキーボードやマウスにして遊んでいた頃から、「カメラだけでポインタを動かせたらもっと身軽なんじゃないか」とずっと考えていた。そんなときに 2025 年 9 月 20 日の iOSDC Japan で「iPhone を光学式マウスにする試み」というルーキーズ LT が採択されているのを知り、登壇予定のあおはらさん（未踏 IT 同期）からタイトルだけ聞かせてもらった。

発表は見られなかったけれど、その一言でスイッチが入り、天下一キーボードの朝 0 時から自分でもゼロから作ってみることにした。iPhone を軽く振るだけでカーソルが走りるようにはできた。

## 仕組み

構成はこれまでの Smartphone Keyboard Connector と同じで、iPhone から Bluetooth で XIAO にデータを送り、XIAO が USB マウスとして PC に接続される。違いはタッチ操作の代わりにカメラ映像の動きそのものをポインタに変換しているところ。

```
iPhone（カメラ + オプティカルフロー解析）
        ↓ Bluetooth LE
XIAO（USB HID ブリッジ）
        ↓ USB-C
PC / Vision Pro / AR グラス
```

## フローのイメージ

<<図：連続する 2 枚のカメラフレームを並べ、同じ模様を矢印で結んでベクトルが描かれているイラスト>>

オプティカルフローは連続するフレームの中から同じ模様を探し、「さっきより右に何ピクセル動いた」「下に少し流れた」といった変化をベクトルとして取り出す手法だ。昔の光学式マウスが LED で机を照らして模様の流れを読むのと同じ発想で、今回は iPhone のカメラが周囲の風景を撮り、その模様の移動量を平均して端末全体の動きに置き換えている。難しい数式を知らなくても、隣り合う画像のズレを矢印に変換しているだけだと思えばイメージしやすいはず。

## 実装

iPhone 側では Vision のオプティカルフロー API を使って毎秒二十数回のペースでフレーム間の動きを計測し、得られたベクトルを滑らかにするためのフィルタを噛ませている。細かい手ブレやノイズは一定のしきい値で切り捨て、残った分だけをマウス移動量に換算して Bluetooth で送信する仕組みだ。

スマホを机に方にカメラを向けて、少しだけ離した姿勢で固定。今回は専用のケースを 3D プリンターで作った。完全にカメラ部分を囲ってしまい外光を遮断し、ライトをオンにすることである程度固定したカメラ入力を取れるようになっている。ただまあカメラとライトの位置関係的に左側だけ光が強いみたいな方よりもあるので完璧ではない。もっと精度を高めるならケース側で女優ライトみたいな円形に配置したライトがあるべきだ。

カメラ周りの調整が想像以上に重要で、特に露出とライト。暗い場所ではカメラのゲインを上げつつフラッシュ LED を弱めに点灯させると流れが安定し、明るい屋外では露出を下げて白飛びを防いだ。モードを切り替えるたびに撮影セッションを初期化し直すことで、徐々に数値がズレていくドリフトも抑えられた。

## UI

マウスモードに入ると画面上部に二つのスライダーを出している。ひとつは「どれくらい振ったらカーソルが進むか」を決める感度、もうひとつはカメラの明るさを決める露出調整だ。値を変えると即座に保存され、マウスモードへ戻った瞬間に前回の設定で再開するので、場所ごとに毎回調整し直す必要がない。LED の点灯やカメラの再起動もこのタイミングで自動化した。

## 使い道

ない。

爆熱だしラグいしまだ使えたものじゃない。しかも接写のできるカメラがあるほうがいいから iPhone Pro シリーズが望ましい。つまり 1 台 20 万円弱の高級マウス。

でもまあこういうくだらなのを作るのは楽しいね。

## 課題

とはいえ課題も多い。テクスチャの少ない真っ白な壁や真っ黒な机に向けるとフローが取れず、紙とか模様のあるマウスパッドのほうが良い。

端末を素早く振ると座標が流れることがある。ローリングシャッター特有の歪みだとこれは思う。補正には IMU とのセンサーフュージョンが欲しくなる。さらにカメラと LED と Bluetooth を同時に動かすのでバッテリー消費と発熱はそれなりにあり、長時間運用には冷却や電源の工夫が欠かせない。
